Nova Experiência para Gestão de Comissões

Redesign da visualização de ganhos, melhorando leitura, organização e entendimento dos pagamentos.

Empresa

Franq

Ano

2022

Área

UX · UI · Produto Web

Papel

UX Designer

Contexto

A tela "Meus Ganhos" é onde o Personal Banker acompanha todo o pipeline das suas vendas em formato Kanban, passando pelas etapas Em Processo, Nota Fiscal, Pagamento e Finalizado. O layout existente era denso, pouco escaneável e não comunicava bem o status de cada negócio, gerando dúvidas frequentes e chamados ao suporte.

ANTES DEPOIS

Processo

Parti de um levantamento das principais queixas dos usuários sobre a tela e analisei o padrão de uso dos filtros e das informações mais acessadas em cada card. Criei uma versão wireframe para validar a hierarquia de informações antes de partir para o visual, testando a distribuição dos status, os rótulos de cor e a ação de visualização rápida do demonstrativo. Desenhei também as variações responsivas para MacBook Air, MacBook Pro 14", 16" e Desktop.

Solução

O redesign trouxe cards com hierarquia visual mais clara, badges de status com cores semânticas consistentes (amarelo para atenção, verde para em andamento, vermelho para recusado, azul para finalizado), filtros reorganizados no topo e uma ação de download do demonstrativo mensal mais acessível. Além do Kanban, desenhei também uma versão lista que oferece uma visão tabular das vendas com colunas de Status, Cliente, Categoria, Valor Bruto, Comissão, Data e Etapa, dando ao PB a flexibilidade de escolher a visualização que melhor se adapta ao seu fluxo de trabalho. Entreguei especificações de responsividade para cada breakpoint e documentação de componentes para o time de desenvolvimento.

Resultados

Interface com leitura de status significativamente mais rápida, com redução de dúvidas operacionais dos PBs sobre o andamento das suas vendas.
